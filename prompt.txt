# 4. GLOBAL PIXEL ECONOMY

These rules are mandatory.

| Mechanic | Rule |
|---|---|
| Global capacity | 1,000,000 pixels |
| Canvas dimensions | 1000 × 1000 |
| Cooldown | 30 seconds per player |
| Canvas | Shared by everyone |
| Pixel replacement | Does not consume another slot |
| Undo | Only eligible own placements |
| Online counter | Authenticated active players |
| Artwork | Downloadable PNG |
| Tasks | Random + daily |

## Pixel capacity rules

- A new empty position consumes one global pixel slot.
- Changing an already occupied position does not consume another slot.
- Clearing an occupied position makes that slot available again.
- Maximum occupied positions: 1,000,000.
- Never allow the global capacity to exceed 1,000,000.
- Calculate remaining pixels using actual occupied positions.

Display:

- Pixels Used: 000,000 / 1,000,000.
- Pixels Remaining.
- Completion Percentage.
- Active Contributors.

All values must come from actual database records.
